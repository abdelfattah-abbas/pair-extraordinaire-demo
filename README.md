# Pair Extraordinaire Demo. This repository is an isolated demonstration of a small, co-authored documentation change. It is separate from the cloud infrastructure project and contains no deployment code, credentials, or production configuration. Safe demo workflow: keep experiments in a dedicated repository so they cannot affect production infrastructure; make a focused change on a short-lived branch; record genuine co-authorship in the commit message with a Co-authored-by trailer; review the diff and merge only after confirming it contains the intended documentation change. Scope: this repository exists only to demonstrate GitHub collaboration. Do not add cloud resources, secrets, Terraform state, or environment-specific settings here.
